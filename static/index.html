Collection

Downloaded through Open-Meteo, a free weather API.

Every file checked before saving: no missing hours, no empty values, nothing physically impossible.

What was recorded every hour

  • Temperature
  • Humidity
  • Dew point
  • Air pressure
  • Wind speed
  • Wind direction
  • Cloud cover
  • Rain and snowfall
  • Snow on the ground
  • Sunlight
  • Each day becomes 17 values per place, such as the mean, lowest and highest temperature.
  • Wind direction becomes a north and an east part, because 359° and 1° are neighbours.
  • No scaling needed: decision trees only compare values with thresholds.

How it works

Five steps of the knowledge discovery (KDD) process, from raw data to a tested model.

  1. 1

    Selection

    Hourly weather for Ulaanbaatar and upwind places, 1980 to 2025.

  2. 2

    Preprocessing

    Every file checked; hours turned into 17 daily values per place.

  3. 3

    Transformation

    Normal subtracted (the anomaly), then lags, averages and upwind differences: 158 features.

  4. 4

    Data mining

    Feature selection, then one CatBoost model per day ahead.

  5. 5

    Evaluation

    Test on 2023 to 2025, baselines, error analysis, SHAP.

Why predict the anomaly?

  • The seasons are known in advance.
  • So the model predicts only the hard part: warmer or colder than normal.
  • The normal is added back at the end.

Why use upwind places?

  • Weather in Mongolia mostly moves from the west and north.
  • What happens in Khovd or Mörön today often reaches Ulaanbaatar 1 to 3 days later.

Gradient boosting

  • An ensemble of many small decision trees, trained one after another.
  • Each new tree corrects the errors left by the trees before it.
  • Unlike bagging, where trees are trained separately and averaged.

How each tree is grown

  • Each split is chosen to reduce the squared error the most.
  • The regression version of Gini impurity or information gain.
  • CatBoost trees are symmetric: every node on a level asks the same question.

Model

Three CatBoost models, one for each day ahead. Each predicts how far the day will be from normal.

Model card

The main facts about the deployed model.

Data split

  • Split by time, never at random: neighbouring days are almost identical, so a random split would overstate accuracy.
  • Every model is tested on later years than it learned from.
  • 3 days removed at each border, so no answer leaks into the next part.

Model selection

Three libraries, same data, default settings. Validation error (RMSE, °C), lower is better.

Feature selection

  • Filter: 32 near-duplicate features removed (correlation above 0.95).
  • Ranking: the rest ranked by permutation importance on the validation data.
  • Kept: the top 40 of 158, where the error stops improving.

Hyperparameter tuning

A small improvement. Day 3 got much stronger L2 regularization, likely because it is noisier and easier to overfit.

Explainability (SHAP)

How much each feature moves the forecast on average (mean absolute SHAP, 2023 to 2025). Top 10 from the four Mongolian places.

Leakage checks

Leakage: the model secretly sees the answer during training, so scores look better than real forecasts.

  • Time split with gaps. Training, validation and test never overlap.
  • Past data only. A test replaces all later weather with random numbers; no feature changes.
  • Normals from training years only. Fitted on 1980 to 2019.
  • Locked test set. Scored once; testing a different model is refused.
  • Same code live and in training. A test confirms identical features.

Known limitations

  • Reanalysis, not station data. A grid, so it can differ from a city weather station.
  • A few hours of hindsight. ERA5 evening values include some next-morning observations: at most 0.17° on the 1 day score.
  • Validation used many times. Selection, tuning and early stopping all used 2020 to 2022, so the test score is the fair one.
  • Cautious in unusual weather. Forecasts stay closer to normal during rare warm or cold spells.
  • Daily mean only. 12 PM and 8 PM are the daily mean plus that day's swing from the weather service, not separate forecasts.
